# Notes de lecture du plan frontend

Notes de travail qui ont fondé les décisions de
[PLAN-FRONTEND-DASHBOARD.md](../PLAN-FRONTEND-DASHBOARD.md), relevées du 18 au 21/09/2026. Le plan
les cite sous la forme `reads/<fichier>.md Lnn` ou `<fichier>.md Lnn` : c'est ce dossier, à la ligne nn.

Elles disent **d'où vient un constat** ; elles ne sont pas nécessaires pour implémenter, le plan
reformule chaque décision et sa preuve dans le code.
